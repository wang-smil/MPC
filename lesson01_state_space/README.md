# 第一课：状态空间模型

## 学习目标

- 理解质量—弹簧—阻尼系统
- 将二阶微分方程转换成状态空间模型
- 使用 Python Control 进行时域仿真
- 根据系统极点判断稳定性

## 物理模型

质量—弹簧—阻尼系统满足：

m·ẍ + c·ẋ + k·x = F

参数：

- 质量 m = 1.0 kg
- 阻尼 c = 0.8 N·s/m
- 弹簧刚度 k = 4.0 N/m
- 外力 F = 1.0 N

## 状态定义

选择位置和速度作为状态：

- x₁ = x：位置
- x₂ = ẋ：速度

状态方程：

ẋ₁ = x₂

ẋ₂ = -(k/m)x₁ -(c/m)x₂ +(1/m)F

对应矩阵：

A = [[0, 1],
     [-4, -0.8]]

B = [[0],
     [1]]

C = [[1, 0],
     [0, 1]]

D = [[0],
     [0]]

## 系统极点

系统极点：

-0.4 ± 1.9596j

极点实部为负，因此系统稳定。

极点包含虚部，因此系统会产生逐渐衰减的振荡。

## 仿真结果

从第 1 秒开始施加 1 N 恒定外力：

- 系统先产生振荡
- 阻尼使振荡逐渐衰减
- 最终速度趋近 0
- 最终位置趋近 F/k = 0.25 m
